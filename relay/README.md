# Обработчик заявок → Telegram

Форма на сайте не может писать в Telegram напрямую: для этого токен бота
пришлось бы положить в скрипт, открытый всем посетителям. По такому токену
посторонний пишет в канал от имени бота, читает переписку и удаляет сообщения.
Поэтому между сайтом и Telegram стоит воркер — токен лежит в нём.

## Что нужно сделать один раз

**1. Бот**

@BotFather → `/newbot` → получите токен вида `1234567890:AA...`.
Никому его не пересылайте, в том числе в переписке.

**2. Канал**

Создайте канал (или используйте существующий), добавьте бота
администратором с правом публикации. Узнать id канала: перешлите любое
сообщение из канала боту @userinfobot — он покажет id вида `-1001234567890`.

**3. Воркер**

1. dash.cloudflare.com → Workers & Pages → Create → Worker → имя, например `mb-lead`
2. Deploy, затем Edit code — вставьте содержимое `worker.js`, снова Deploy
3. Settings → Variables and Secrets → добавьте **как Secret**:
   - `BOT_TOKEN` — токен из шага 1
   - `CHAT_ID` — id из шага 2
4. Скопируйте адрес воркера, он будет вида `https://mb-lead.<ваш>.workers.dev`

**4. Сайт**

В `config.js` в корне сайта впишите адрес:

```js
formEndpoint: 'https://mb-lead.<ваш>.workers.dev'
```

Форма появится на страницах сама — пока адрес пустой, она скрыта.

## Проверка

```bash
curl -X POST https://mb-lead.<ваш>.workers.dev \
  -H 'Content-Type: application/json' \
  -H 'Origin: https://m-brokers.uz' \
  -d '{"name":"Проверка","phone":"+998901234567","page":"тест"}'
```

Ответ `{"ok":true}` и сообщение в канале.

## Что уже предусмотрено

- Принимаются запросы только с m-brokers.uz (CORS), с остальных — 403
- Номер короче 9 цифр отбрасывается
- Скрытое поле-ловушка на сайте отсеивает ботов, заполняющих все поля подряд
- Ответ Telegram наружу не отдаётся: в нём бывает эхо токена
