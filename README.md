# М-Брокерс — сайт

ООО «Marishka Brok», таможенный представитель в Реестре ГТК РУз (разрешение №04-05/20-4360 от 23.08.2014).
Ташкент, Яшнабадский р-н, ул. Корасув, 4. Почта: info@raztamojka.uz, Telegram: @MB_Customs_Broker.

## Что готово

- `index.html` — главная. Собрана из макета Claude Design (`Home.dc.html`,
  проект «Marishka Brok сайт дизайн»).
- `about.html` — о компании: чем таможенный представитель отличается от посредника,
  документы, реквизиты, отзывы.
- `contacts.html` — контакты: телефон, Telegram, почта, реквизиты, карта проезда.
- `services.html` — услуги: брокер, оформление, сертификация, склад (якоря
  `#broker`, `#clearance`, `#certification`, `#warehouse`).
- `404.html` — с телефоном и разделами вместо пустой страницы GitHub.
- `uz/` — узбекская версия всех страниц (латиница).
- `fonts/` — самохостинг Oswald и Inter, по файлу на диапазон символов.
- `sticky.js` — плавающая шапка: клонирует `.topbar` и показывает копию,
  когда первый экран (`.hero` или `.pagehead`) ушёл наверх.
- `site.css` — общие стили всех страниц. При правке стилей поднимайте версию
  в `href="site.css?v=N"` во всех html, иначе у вернувшихся посетителей
  останется старый файл из кеша.

Двуязычный, ru в корне и uz в `/uz/`, связаны через `hreflang` и переключатель
RU/OZ в шапке. Без сборки и зависимостей, просто статика.

Шрифты Oswald (заголовки) и Inter (текст) лежат в `fonts/`, внешних origin нет.
**Archivo из макета не используется: у него нет кириллицы**, весь русский текст
рендерился системным шрифтом. Карта Яндекса (41.293607, 69.341031) грузится
по клику — виджет весит больше всей остальной страницы.

Картинки в webp с jpg-фолбэком, у героя три ширины через `srcset`.
Пересобирать после замены исходников — скриптом из истории коммита `a2bdff1`.

Секции главной: герой с шапкой и полосой фактов → «Что обычно ломает поставку»
(6 пунктов) → «Услуги» (4 строки) → «Не посредник, а таможенный представитель»
+ документы → «Клиенты» → «Офис» с картой → красный CTA-блок → подвал.

Было 364 KB плюс два внешних origin под шрифты и виджет Яндекса,
который грузился при открытии страницы.

## Ещё не сделано

Битых ссылок нет: четыре услуги живут якорями на одной `services.html`.

в проекте Claude Design.

конверсию сейчас измерить нечем. Нужен идентификатор GA4 или Яндекс.Метрики
от клиента.
