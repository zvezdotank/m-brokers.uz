## Что готово

`index.html` — главная. Собрана из макета Claude Design
(`Home.dc.html`, проект «Marishka Brok сайт дизайн»).

Один самодостаточный файл: разметка + стили внутри, без сборки и зависимостей.
Шрифты Oswald + Archivo подключены с Google Fonts.

Секции: герой с шапкой и полосой фактов → «Что обычно ломает поставку» (6 пунктов)
→ «Услуги» (4 строки) → «Не посредник, а таможенный представитель» + документы
→ «Клиенты» → красный CTA-блок → подвал.
